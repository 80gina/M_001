# 제철밥상 플래너 2.0 기능설명서\n\n> 제철 식재료와 가격을 이해하는 AI 장보기 비서

## 1. 서비스 개요

제철 식재료 가격, 계절성, 음식 추천, 장바구니 계산을 한곳에서 제공하는 PC·모바일 반응형 웹앱이다. 1차 사용자는 일반 가정 사용자이며, 요리교실 강사는 강사 모드로 확장 기능을 사용한다.

## 2. 주요 사용자

| 사용자 | 주요 목적 |
|---|---|
| 일반 가정 사용자 | 오늘 살 재료와 식단을 빠르게 결정 |
| 요리교실 강사 | 인원·예산에 맞는 식단과 장보기 목록 작성 |

## 3. 메뉴 구조

홈 → 식단 만들기 → 장바구니 → 시장 방문 → 가격 탐색 → 내 기록 → 더보기

## 4. 핵심 기능

### 홈

- 이번 달 제철 재료
- 가격이 내려간 재료
- 오늘의 추천 식단
- 장바구니 예상 금액
- 마지막 데이터 업데이트 시간

### 식단 만들기

- 인원 선택
- 예산 선택
- 조리 시간·난이도 선택
- 제철 중심·절약 중심 선택
- 알레르기·제외 재료 입력
- 음식 추천 및 재료 장바구니 담기

### 장바구니

- 재료와 수량 관리
- 1인·가족·수업 인원별 자동 환산
- 예상 총액과 예산 잔액 표시
- 가격이 높은 재료의 대체재 제안
- 공유 링크·이미지·CSV·PDF 출력

### 가격 탐색

- KAMIS 가격 데이터 조회
- 일별 가격 그래프
- 7일·30일 이동평균
- 월별 계절 지수
- 전주·전년 동기 비교
- 가격 변동성·시계열 분해
- 기온과 가격 관계 분석

### 시장 방문

#### 사진 인식

1. 재료 사진 촬영
2. 재료명 후보와 인식 신뢰도 표시
3. 품목·품종·단위 확인
4. 가격 입력 또는 확인
5. KAMIS 평균가격 비교
6. 장바구니 저장

#### 바코드 인식

1. 바코드 스캔
2. 상품명·제조사·중량 확인
3. 판매가격 입력
4. 단위가격 자동 환산
5. 평균가격과 비교
6. 장바구니 저장

#### 직접 기록

- 재료명·수량·단위·가격 직접 입력
- 영수증 사진은 2차 기능으로 확장

## 5. 데이터 안전 원칙

- 사진·바코드 인식 결과는 자동 확정하지 않는다.
- 사용자가 확인·수정한 뒤 저장한다.
- 가격 데이터가 부족하면 분석 결과 대신 “데이터 부족”을 표시한다.
- KAMIS·기상청 인증키는 서버 환경변수에만 저장한다.
- API 키, Firebase 서비스 계정 파일, 개인정보가 포함된 스크린샷은 저장소에서 제외한다.

## 6. 강사 모드

- 수업 인원·회차·예산 입력
- 1인 재료비 계산
- 회차별 식단 구성
- 대량 장보기 수량 계산
- 수업용 가격 그래프
- 분석 리포트와 장보기 목록 출력

## 7. 기존 업로드 프로젝트와의 연결

| 기존 모듈 | 연결 화면 |
|---|---|
| `summary_service.py` | 홈의 가격 판정 |
| `recommend_service.py` | 식단 만들기 |
| `alternatives.py` | 대체 재료 |
| `statistics_service.py` | 가격 탐색 |
| `forecast_service.py` | 가격 추이 예측 |
| `chat_service.py` | AI 도움받기 |
| `data.py` 라우터 | 가격·통계 API |
| `conversations.py` | 내 기록 |
