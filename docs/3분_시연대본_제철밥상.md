# 제철밥상 플래너 3분 시연 대본

## 0:00~0:25 문제 제시

“장보기 전에 무엇을 살지 정하고, 시장에 가서는 재료와 가격을 다시 확인해야 합니다. 제철밥상 플래너는 식단 추천부터 시장 기록, 장바구니 계산까지 한 흐름으로 연결합니다. 일반 가정 사용자는 간단하게, 요리교실 강사는 인원별 비용까지 확인할 수 있습니다.”

## 0:25~0:55 밥상 추천

홈 화면에서 ‘밥상추천’을 선택합니다. 인원과 조리 시간, 원하는 밥상 느낌을 입력합니다.

“2인, 30분 이내, 따뜻한 국물을 선택해 보겠습니다. 배추된장국, 제철 채소 비빔밥, 애호박 볶음 정식이 추천됩니다. 추천 결과는 재료 준비로 바로 연결됩니다.”

## 0:55~1:35 시장 방문 사진 인식

‘시장담기’에서 사진을 선택합니다. 채소·과일뿐 아니라 돼지고기·소고기·닭고기, 고등어·오징어·새우 같은 육류·수산물도 대상입니다.

“사진을 올리면 후보를 최대 3개까지 보여줍니다. 예를 들어 돼지고기 사진이라면 돼지고기, 소고기, 새우 후보가 표시됩니다. 인식 결과를 자동 확정하지 않고 사용자가 직접 후보를 선택하게 해 오인식을 줄입니다.”

후보를 선택한 뒤 가격과 단위를 확인하고 장바구니에 담습니다.

## 1:35~2:05 바코드와 KAMIS 가격

‘바코드’ 탭에서 카메라 스캔 또는 숫자 입력을 시연합니다.

“포장식품이나 축산·수산물은 바코드로 상품을 찾을 수 있습니다. 홈 화면의 KAMIS 시세 영역은 서버 API를 통해 채소류·축산물·수산물 가격을 받아옵니다. 인증키는 프론트에 노출하지 않고 백엔드 환경변수에서만 사용합니다.”

시세가 연결되지 않는 경우에도 직접 가격 입력으로 흐름을 이어갑니다.

## 2:05~2:35 장바구니와 강사모드

장바구니에서 수량을 조절하고 예상 합계를 확인합니다.

“요리교실 강사는 강사모드에서 수업 인원을 입력하면 1인 예상 비용을 확인할 수 있습니다. 장보기 목록은 클립보드로 복사해 수업 준비에 활용할 수 있습니다.”

## 2:35~3:00 팀미션 연결과 마무리

“이 프로젝트는 데이터 CRUD와 가격 요약, AI 추천·채팅, 대화 저장 구조를 갖춘 AI 데이터 비서입니다. RAG는 가격·식재료 근거를 검색해 답변에 활용하고, Long-term Memory는 사용자별 선호·장바구니·대화 이력으로 확장합니다. 현재는 KAMIS 실데이터 검증과 실제 비전/OCR 연결을 최종 보완 과제로 관리하고 있습니다. 사용자가 시장에서 발견한 재료를 따뜻한 한 끼로 연결하는 것이 제철밥상 플래너의 핵심입니다.”
