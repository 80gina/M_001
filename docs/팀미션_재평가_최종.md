## 최종 제출 전에 반드시 할 일

1. KAMIS 키와 서비스 계정 키 폐기·재발급
2. 2년 시계열 데이터의 중복·결측·단위 검증
3. RAG 검색 근거가 화면에 표시되는 장면 추가
4. 사용자별 선호 저장과 재방문 시 불러오기 시연
5. 사진 후보 선택과 KAMIS 현재가격 조회의 실제 성공 화면 캡처

따라서 발표·프로토타입 기준으로는 팀미션에 적합합니다. 다만 RAG, 장기기억, 실데이터 품질을 심사자가 직접 확인하는 미션이라면 위 5개 항목을 완료해야 “완전 적합”으로 판정할 수 있습니다.
