# 제철밥상 플래너 2.0 시연자료

## 시연 목표

일반 사용자가 시장에서 재료를 확인하고, 가격을 비교한 뒤, 예산에 맞는 식단과 장보기 목록을 만드는 과정을 보여준다.

## 시연 순서

### 1. 홈 화면

“오늘 장보기, 알뜰하게 시작해요” 화면에서 9월 제철 재료와 가격이 내려간 재료를 확인한다.

### 2. 식단 만들기

4인 가족, 3만 원 이하, 30분 이내, 제철 중심 조건을 선택한다.

추천 결과에서 음식 하나를 선택하고 재료를 장바구니에 담는다.

### 3. 장바구니 확인

배추·무·대파·양파의 수량과 예상가격을 확인한다.

예산 잔액과 1인 예상 비용을 확인한다.

### 4. 사진 인식

시장 방문 메뉴에서 애호박 사진을 촬영한다.

인식 결과 “애호박 92%”를 확인하고 수량과 가격을 수정한다.

### 5. 바코드 인식

포장 양파의 바코드를 스캔한다.

상품명·중량·가격을 확인하고 kg당 가격으로 환산한다.

### 6. 가격 비교

KAMIS 평균가격과 매장 가격을 비교한다.

일별 가격·7일 이동평균·30일 이동평균 그래프를 보여준다.

### 7. 대체 재료

가격이 높은 재료를 선택하고 대체 식재료를 확인한다.

### 8. 강사 모드

12명·90분·1인 예산 8,000원을 입력한다.

수업용 식단과 총예상비용, 1인 비용, 장보기 목록을 확인한다.

## 예상 질문과 답변

| 질문 | 답변 |
|---|---|
| 왜 제철밥상인가요? | 가격 데이터와 계절성을 함께 활용해 실제 장보기 결정을 돕기 위해서입니다. |
| AI가 가격을 마음대로 판단하지 않나요? | 서버가 계산한 가격 지표와 판정을 근거로 AI가 설명합니다. |
| 사진 인식이 틀리면 어떻게 하나요? | 인식 결과를 사용자가 확인·수정한 뒤 저장합니다. |
| 바코드에 가격도 들어 있나요? | 상품명·중량은 읽을 수 있지만 판매가격은 직접 확인·입력하는 단계가 필요할 수 있습니다. |
| 팀미션의 AI Agent와 어떻게 연결되나요? | Planning Agent는 식단과 장바구니를 계획하고, Coaching Agent는 가격과 대체재를 설명합니다. |
| RAG는 어디에 사용하나요? | 제철 기준, 음식 정보, 대체재료 지식과 가격 데이터 요약을 검색·주입합니다. |

## 시연 시 주의사항

- API 키가 포함된 화면을 보여주지 않는다.
- 실제 2년 데이터가 준비되기 전에는 “시범 데이터”라고 표시한다.
- 가격 예측은 참고값이라고 설명한다.
- 인식 결과를 자동 확정하지 않는다.
- 서버가 절전 상태일 경우 미리 헬스체크를 실행한다.
