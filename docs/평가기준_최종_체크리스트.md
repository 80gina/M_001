## C. AI 핵심 기술 요소

| 요소 | 상태 | 구현 증거 | 시연 포인트 |
|---|---|---|---|
| AI Agent | ✅ | 11개 도구, 최대 3라운드 호출 | “요즘 값이 어때?” 질문 |
| RAG/검색 증강 | ✅ | 가격·통계·도메인 지식 조회 후 컨텍스트 주입 | 답변의 수치 근거 설명 |
| Long-term Memory | ✅ | 대화 저장·목록·전체 메시지 불러오기 | 이전 대화 선택 후 이어 묻기 |
| 자동화 워크플로우 | ✅ | 요약→판정→도구→답변→저장 | 한 번의 질문으로 전체 과정 수행 |
| 멀티모달 | ⚠️ 프로토타입 | 사진 미리보기·후보 선택 UX | 운영 비전 모델은 후속 범위라고 설명 |
