# 제철밥상 플래너 2.0 시연 순서 정리보고서

> 제철 식재료와 가격을 이해하는 AI 장보기 비서

## 1. 시연 목표

3분 안에 ‘사용자 문제 → 해결 흐름 → AI 기술 → 실제 성과 → 한계와 계획’을 보여줍니다. 화면 기능을 빠르게 넘기기보다 각 장면이 어떤 평가 기준의 증거인지 한 문장으로 연결합니다.

## 2. 시연 준비

| 준비 항목 | 내용 |
|---|---|
| 브라우저 탭 1 | 공개 Vercel 간편 화면 |
| 브라우저 탭 2 | 고급 AI 비서 화면 또는 API `/docs` |
| 브라우저 탭 3 | GitHub README와 체크리스트 |
| 사진 | 파일명에 `배추`, `돼지`, `고등어` 중 하나가 포함된 샘플 |
| 바코드 | `8800000000003` 돼지고기, `8800000000004` 고등어, `8800000000005` 오징어 |
| AI 질문 | “요즘 값이 어때?”, “수산물 중 살 만한 것은?” |

## 5. 평가자 질문 대비

### “사진 인식이 실제 AI인가요?”

현재 공개 데모는 사진 미리보기와 사용자 확인형 후보 UX를 검증한 프로토타입입니다. 운영용 비전 모델은 아직 연결하지 않았으며 이를 제출 문서에 명시했습니다.

### “RAG에 벡터 DB가 있나요?”

이 프로젝트는 문서 임베딩형 RAG 대신 구조화 데이터 검색 증강을 사용합니다. Agent가 가격 기록·통계·품목 지식·이전 대화를 도구로 조회해 답변 컨텍스트에 넣습니다.

### “AI 답변의 환각은 어떻게 줄였나요?”

가격 판정은 GPT가 아니라 서버의 고정 계산식으로 결정합니다. GPT에는 판정과 근거 문장을 함께 전달하고 그 범위에서 설명하도록 제한합니다.

### “일반 사용자와 강사 기능이 왜 같은 앱에 있나요?”

두 사용자 모두 식재료 선택과 장보기라는 공통 작업을 합니다. 가정 사용자는 간단한 식단 결정을, 강사는 같은 장바구니를 인원별 비용으로 확장해 사용합니다.
