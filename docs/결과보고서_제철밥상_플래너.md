# 제철밥상 플래너 2.0 결과보고서

## 1. 프로젝트 개요

제철 식재료 가격과 계절성 데이터를 활용해 일반 가정 사용자가 식단과 장보기 계획을 세울 수 있도록 지원하는 AI 웹앱을 설계했다. 요리교실 강사는 인원과 예산을 입력해 수업용 식단과 장보기 목록을 만들 수 있다.

## 2. 문제 정의

사용자는 식재료 가격을 확인하기 위해 여러 서비스를 오가야 하며, “제철이면 실제로 저렴한가”를 판단하기 어렵다. 기존 프로젝트는 가격 분석 기능이 풍부하지만 CLI와 복잡한 대시보드 중심이어서 일반 사용자가 바로 쓰기 어려웠다.

## 3. 해결 방법

- 홈에서 오늘의 제철·가격 정보를 요약한다.
- 식단 조건을 단계별로 입력하게 한다.
- 추천 식단의 재료를 장바구니에 바로 담는다.
- 시장에서는 사진·바코드·직접 입력으로 재료를 기록한다.
- 가격 분석은 품목 상세 화면에서 제공한다.
- 고급 통계와 강사 기능은 별도 모드로 분리한다.

## 4. 구현 기반

기존 FastAPI 백엔드, Vanilla JavaScript 프론트엔드, 가격 요약·추천·대체재료·통계·예측·대화 서비스를 활용한다. 업로드된 프로젝트에는 `/api/data`, `/api/recommend`, `/api/chat`, `/api/conversations` 등 핵심 API가 이미 구성되어 있다.

## 5. 성과

1. 복잡한 기능을 홈·식단·장바구니·시장 방문·가격 탐색으로 재구성했다.
2. 일반 가정 사용자를 1차 사용자로 명확히 설정했다.
3. 요리교실 강사용 인원·예산·대량 구매 기능을 분리했다.
4. 사진 인식과 바코드 인식을 장바구니 흐름에 연결했다.
5. 인식 결과를 사용자가 확인하는 안전장치를 정의했다.
6. 팀미션의 AI Agent·RAG·장기기억·문서화 요구와 연결했다.

## 6. 확인된 한계

현재 업로드된 가격 CSV는 2026-09-09 하루치 446행이며, 2년치 일별 시계열로 사용할 수 없다. 같은 날짜에 품목별 여러 가격이 존재하므로 일별 대표값 집계가 필요하다. 또한 인증정보가 포함된 증빙 이미지는 제출 전에 교체해야 한다.

## 7. 개선 계획

### 1단계

- 실제 2년 데이터 재수집
- 날짜·품목별 중앙값 집계
- 데이터 품질 검사 추가

### 2단계

- 사진·바코드 API와 확인 화면 구현
- 장바구니 저장·공유 구현
- 모바일 반응형 QA

### 3단계

- 사용자별 장기기억
- 강사 모드
- 실제 배포와 시연 영상

## 8. 결론

제철밥상 플래너는 팀미션에 적합한 주제와 기술 기반을 갖췄다. 현재는 분석·추천 기능이 먼저 구현된 상태이므로, 데이터 품질과 사용자 흐름을 보완하면 실제 생활과 요리교실에서 사용할 수 있는 AI 서비스로 발전할 수 있다.
